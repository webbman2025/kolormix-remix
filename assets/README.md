# Assets Directory

Place game assets here per `docs/04_art_assets.md`:

- `sprites/` — tile sheets, UI buttons, mascot keyframes
- `audio/sfx/` — merge pop, shake whoosh, wildcard sparkle
- `audio/music/` — menu and gameplay loops
- `backgrounds/` — gameplay and menu backgrounds

The current MVP uses procedural Phaser graphics (rectangles + text) so the game runs without binary assets.
